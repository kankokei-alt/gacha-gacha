2全体の仕組み

アプリは GitHub に置いたファイルを、2人のスマホがそれぞれ開いて使います。2人の間のやりとりは LINE で送るリンク だけです。

👉 図は横にスクロールできます

ポイント：サーバー（データを預かるコンピューター）はありません。だから無料で、記録が外に漏れる心配もありません。そのかわり、2人の間のやりとりは LINE でリンクを送り合う形になります。

32人の役割

👩 ハル（あそぶ人）

アプリの4つのタブ

  • 🎰 ガチャ：🎫1枚でハンドルを回してカプセルを開ける
  • 💪 がまん：本物をがまんしたら「がまんした！」を押す → LINE で送る
  • 🎁 ごほうび：当たったチケットの一覧。「使う」で使用済みに
  • 📖 ずかん：キャラ・レベル・実績

👨 だんなさん（管理する人）

管理ページ admin.html でできること

  • ✅ 認定 / 🙅 見送り：申請のリンクを開いて判断。枚数とひとことも変えられる
  • 🎁 プレゼント：いつでもガチャ券を贈れる
  • 📊 今月のまとめ：認定した額・使われたご褒美・家計のトク
  • 🍮 ご褒美の実行：「使います」と届いたら本物を用意する

4はじめの準備（1回だけ）

  1. だんなさん管理ページをひらく自分のスマホの Safari で https://kankokei-alt.github.io/gacha-gacha/admin.html を開く。
    ※ ホーム画面には追加しないでください（理由は⑨）。ブックマークしておくと便利です。
  2. だんなさんカギを作る呼び名（例: だんなさん）と奥さんの呼び名（ハル）を入れて「🔑 カギを作って管理をはじめる」。
  3. だんなさんつなぐリンクを送る「つなぐリンクを送る」→「LINEで送る」でハルに送信。
  4. ハルリンクをタップ「〇〇とつながりました！」と出ればOK。2人の画面に出る あいことば（例: AB12-CD34）が同じか確かめる。
  5. ハルホーム画面に追加アプリのほうは Safari の共有ボタン →「ホーム画面に追加」すると、アプリのように使えます。
ハルがアプリをすでにホーム画面に追加している場合、④のリンクは Safari で開くので、アプリには届きません。そのときはリンクをコピーして、アプリの ⚙️ →「📋 コードを貼りつける」から読みこんでください。

5がまん認定の流れ

毎回の流れです。LINE の「送信」を押すところだけ、手でやる必要があります。

👉 図は横にスクロールできます

🙅
見送りにしたとき

ハルのアプリに「今回は見送り」とひとことが届き、ガチャ券は増えません。

📮
送り忘れ・届かないとき

ハルは「認定まち」から、だんなさんは「りれき」の「再送」から、もう一度送れます。

9データと安全

🔑
認定はだんなさんにしかできない

認定リンクには、管理ページの「秘密カギ」で作った印がつきます。秘密カギはだんなさんのスマホから出ないので、ハルが自分で認定リンクを作ることはできません。1文字でも書き換えると無効になります。

🔁
同じリンクは1回だけ

認定リンクは申請ごとに1つ。2回タップしてもガチャ券は増えません。

📱
記録はスマホの中だけ

ガチャ券・ご褒美・ずかんはハルのスマホに、認定のりれきはだんなさんのスマホに保存。外には送られません（LINEで送るリンクの中身を除く）。

🧭
「ブラウザごと」に別の記録

同じスマホでも、Safari・ホーム画面のアプリ・LINEの中のブラウザは、それぞれ別の記録になります。

だから管理ページは Safari で：秘密カギは Safari の中に保存されます。LINE のリンクは自動で Safari で開くようにしてあるので、管理ページは Safari で使えば迷いません。ホーム画面に追加すると、そちらにはカギがないので認定できなくなります。
バックアップ：
・ハル：アプリの ⚙️ →「バックアップ」の「コピー」
・だんなさん：管理ページ下の「カギのバックアップ」→「コピー」（人に見せないでください）
機種変更のときは、新しいスマホでそれぞれ貼りつけて戻します。
できないこと：ガチャの抽選はハルのスマホの中で行っています。パソコンに詳しい人がブラウザの記録を直接書き換えることまでは防げません。家庭内の遊びとして割り切った作りです。

10変えたいとき

いちばん簡単なのは Claude に頼むことです。直したら GitHub で main に反映すると、1〜2分で公開されます。

頼み方の例

月の出費をもう少し減らしたいので、ログインボーナスを2日に1枚にして。
お寿司チケットを1万円にして、確率は半分に。
「映画チケット 2,000円 1%」を当たりに追加して。
がまん1回でもらえるガチャ券を5枚に増やして。

自分で変えるなら

GitHub で js/data.js を開き、鉛筆マーク ✏️ で編集できます。先頭にこう書いてあります：

{ id: 'sweets', name: 'デザートチケット', emoji: '🍮', value: 300, rate: 0.08, desc: 'コンビニスイーツをひとつ' }, ↑金額 ↑確率(0.08=8%) ↑説明 const GAMAN_TICKETS = 3; ← がまん1回でもらえるガチャ券 const LOGIN_TICKETS = [1, 1, 1, 1, 1, 1, 3]; ← 1〜7日目のログインボーナス
・id（最初の英字）は変えないでください。すでに当たったチケットが分からなくなります。
・変更したら sw.js の1行目付近の pocket-gacha-v11 の数字を1つ上げると、スマホに確実に届きます。
・数字を変えたら、⑦のお金の計算も変わります。Claude に「月の平均はいくらになる？」と聞けば計算できます。

更新の流れ

  1. Claude が作業用ブランチで直すclaude/… というブランチに変更が入ります。
  2. GitHub で main に反映「Pull requests」→「New pull request」→ base: main ← compare: 作業用ブランチ →「Create pull request」→「Merge pull request」→「Confirm merge」。
  3. 自動で公開「Actions」タブで緑の ✅ になれば完了。
  4. スマホで開き直す古いままなら、アプリを一度閉じてもう一度開きます。

11こまったとき

認定リンクをタップしたのに、ガチャ券が増えない

ハルがアプリをホーム画面に追加して使っている場合、LINE のリンクは Safari で開くので、アプリには届きません。リンクを長押しでコピー → アプリの「がまん」タブ（または ⚙️）の「📋 コードを貼りつける」から読みこんでください。

管理ページで「先にカギを作ってください」と出る

カギを作ったのとは別のブラウザで開いています（LINE の中のブラウザ、ホーム画面のアイコンなど）。Safari で開き直してください。それでもダメなら、前に「カギのバックアップ」をコピーしていれば、初期画面の「前に作ったカギを戻す」から戻せます。

カギをなくした（機種変更・履歴を消した）

新しくカギを作り直して、「つなぐリンク」をもう一度ハルに送ってください。ハルのアプリで「つなぎ先を変えますか？」と出るので「変える」を押します。まだ認定していない申請は、ハルに送り直してもらいます。

「この申請が見つかりません」と出る

申請したときと別のブラウザ（またはアプリ）で認定リンクを開いています。申請したほう（ふだん遊んでいるアプリ）で「コードを貼りつける」から読みこんでください。

アプリが新しくならない

① main に反映されているか、② Actions タブで ✅ か、③ アプリを閉じて開き直したか、の順に確認してください。

お金はかかりますか？

かかりません。GitHub・GitHub Pages・LINE の送信はこの使い方なら無料です。かかるのは、当たったご褒美の本物代だけです。
