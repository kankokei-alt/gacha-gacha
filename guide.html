1全体の仕組み

アプリは「GitHub に置いたファイルを、GitHub が自動でWebサイトとして公開し、スマホがそれを読み込む」だけの構造です。サーバーやデータベースはありません。

👉 図は横にスクロールできます

📦
リポジトリ

アプリのファイル一式を保管する場所。Googleドライブのフォルダのようなもの。

🤖
GitHub Actions

main ブランチが更新されると、自動でサイトを作り直してくれる係。

🌐
GitHub Pages

ファイルをWebサイトとして無料で公開してくれるサービス。

ブランチって？
リポジトリの中の「作業用コピー」です。main が本番、claude/zealous-newton-by3jhe は Claude が作業するためのコピーです。
main が変わったときだけ公開サイトが更新されます。

41回のガチャで起きていること

見た目の演出の裏で、プログラムは次の順番で動いています。

  1. 🪙 コインを入れる（ボタンを押す）コインが減り、この瞬間に中身が抽選で決まって保存されます。回した回数もここで数えます。
  2. ↻ ハンドルを回す指で右回りに1周（またはタップ4回）。90度ごとに「カチッ」と音と振動。逆回しは効きません（本物と同じ）。
  3. 💊 カプセルが落ちてくる取り出し口にカプセル。レアなものは金色・虹色のカプセルになりやすい（普通のものもたまに金色のフェイントあり）。
  4. 👆 タップして開けるレア度が高いほどタップ回数が増え、途中で光り出します。
  5. ✨ 結果表示ずかんに登録（NEW）または 💎かけら に変換。XP・ミッション・実績をまとめて判定し、レベルアップや実績達成があれば続けて表示します。
中身は①の時点で決まって保存されているので、途中でアプリを閉じてもカプセルは消えません。次に開くと、取り出し口にカプセルが残っています。

6データの保存

コイン・ずかん・がまん貯金などの記録は、すべてスマホのブラウザの中（localStorage）に保存されます。

🔒
外に送られない

GitHub にも、どこのサーバーにも送られません。他の人からは見えません。

📱
端末ごとに別

スマホとPCで開くと、それぞれ別のデータになります。共有はされません。

🔄
アプリを更新しても消えない

アドレスが同じなら、新しい版を公開してもデータはそのまま残ります。

⚠️
消えるのはこんなとき

ブラウザの履歴・サイトデータを消したとき、アプリを削除したとき、iPhoneのSafariで長期間開かなかったとき。

機種変更・念のための保存：⚙️ →「バックアップ」の「コピー」で長い文字列が出ます。それをメモ帳などに保存しておき、新しいスマホで ⚙️ → 貼りつけ →「読みこむ」で復元できます。

7更新のしかた

一番かんたんなのは、Claude に頼んで直してもらい、それを main に反映する方法です。

  1. Claude に頼むClaude が作業用ブランチ（claude/…）で直して push します。
  2. main に反映するGitHub の「Pull requests」から作業用ブランチ → main へのプルリクエストを作り、「Merge」します（プルリクエスト作成は Claude に頼むこともできます）。
  3. 自動で公開されるGitHub Actions が動き、1分ほどで公開サイトが新しくなります。「Actions」タブで緑の ✅ を確認。
  4. スマホで確認アプリを一度閉じて開き直します。古い画面のままなら、もう一度開き直すと新しい版に切り替わります。

頼み方の例

「ご当地グルメ」のガチャマシンを追加して。シークレットは金色の何かで。
シークレットが出にくすぎるので、確率を倍にして。
がまん貯金のボタンに 100円 と 1000円 を追加して。
ハロウィンの期間だけ出る限定マシンを作って。

自分で少しだけ変えるなら

GitHub の画面上でファイルを開き、鉛筆マーク ✏️ で直接編集できます。js/data.js のアイテムは1行1個で、こう書いてあります：

['pudding', 'とろけるプリン', '🍮', 'N', 'ぷるんとゆれるカラメル色。'], ↑ID(英字・かぶり禁止) ↑名前 ↑絵文字 ↑レア度 ↑ひとこと
注意：すでに持っているアイテムの ID（最初の英字）を変えると、ずかんから消えたように見えます。名前・絵文字・ひとことは自由に変えて大丈夫です。
変更を確実にスマホへ届けたいときは、sw.js の1行目付近の pocket-gacha-v1 を v2、v3… と数字を上げてください。

8よくある質問

お金はかかりますか？

かかりません。GitHub（公開リポジトリ）・GitHub Pages・GitHub Actions はこの使い方なら無料です。アプリ内のコインも本物のお金とは一切つながっていません。

他の人に見られますか？

アプリのアドレスを知っている人は開けます（リポジトリが公開のため）。ただし遊んだ記録は各自のスマホの中だけなので、奥様のずかんや貯金を他人が見ることはできません。

電波がなくても遊べますか？

一度開いたことがあれば遊べます（sw.js が中身を覚えておくため）。

コインが足りなくなったら？

リアルで我慢した分を「がまん貯金」に記録するのが基本です。ほかにログインボーナス・毎日の無料チケット・ミッション・実績でも増えます。

間違えてがまん貯金を記録した

がまん貯金タブの「りれき」で × を押すと消せます。その分のコインも差し引かれます。

最初からやり直したい

⚙️ →「データをぜんぶ消す」で初期状態に戻ります（確認が2回出ます。元に戻せません）。

公開サイトが更新されない

① main に反映されているか（作業用ブランチのままでは公開されません）、② Actions タブで ✅ になっているか、③ スマホでアプリを開き直したか、の順に確認してください。
