# 🎰 ぽけっとガチャ

リアルのガチャガチャを **がまんした分だけ**、スマホで心ゆくまで回せるおうちガチャアプリです。
ホーム画面に追加すればアプリのように使え、オフラインでも遊べます。

## しくみ

```
本物のガチャをがまんする ──▶ 「がまん貯金」に記録（例: 300円）
                                  │
                                  ├─▶ 同じ額の 🪙コイン がもらえる → アプリで思いっきり回す
                                  └─▶ 「ご褒美目標」が進む → たまったら本物のご褒美を買う
```

| 要素 | 内容 |
| --- | --- |
| 🎰 ガチャ | 6種類のマシン（各10種・全60アイテム）。コインを入れて **ハンドルを指で回し**、出てきたカプセルをタップして開ける |
| ✨ 開封演出 | レア度が高いほどタップ回数が増えカプセルが光る。シークレットは虹色演出 |
| 📖 ずかん | 集めたアイテムを確認。未入手はシルエット、シークレットは「？」 |
| 🛟 天井 | 10回つづけてかぶると次は必ず NEW |
| 💎 かけら | かぶりは「かけら」に変換され、ほしいアイテムと交換できる |
| 🐷 がまん貯金 | リアルガチャをがまんした金額を記録 → 同額のコイン。月別グラフと履歴 |
| 🎁 ご褒美目標 | 「カフェでケーキ 1,500円」など目標を決めると、がまん貯金で進捗が進む |
| 🌞 ログボ | 7日サイクルのログインボーナス＋毎日の無料チケット |
| 📋 ミッション | 毎日4つ＋全クリアボーナス |
| 🏅 実績・レベル | 27個の実績。レベルアップで称号と新しいガチャが解放 |
| 🎊 本日のおすすめ | 日替わりで1台が20%OFF |

## 遊び方

1. 「がまん貯金」タブで、がまんした金額のボタン（200〜500円）を押す
2. 「ガチャ」タブでマシンを選んでコインを入れる
3. ハンドルを右にぐるっと回す（タップ4回でもOK）
4. 出てきたカプセルをタップして開ける

## 公開方法（GitHub Pages）

ビルド不要の静的サイトなので、GitHub Pages でそのまま公開できます。

1. このブランチを `main` にマージする
2. GitHub のリポジトリで **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. `main` に push すると `.github/workflows/pages.yml` が自動で公開する（Actions タブから手動実行も可能）
4. `https://<ユーザー名>.github.io/gacha-gacha/` をスマホで開く
5. iPhone: Safari の共有ボタン →「ホーム画面に追加」／ Android: Chrome のメニュー →「ホーム画面に追加」

> 無料プランの GitHub Pages は **公開リポジトリ** が必要です。リポジトリを非公開のままにしたい場合は、
> [Netlify Drop](https://app.netlify.com/drop) や Cloudflare Pages にフォルダごとアップロードしても動きます。

### ローカルで動かす

```bash
npx serve .        # または python3 -m http.server
```

## データについて

- データはその端末のブラウザ（localStorage）にだけ保存され、外部には送信されません
- iPhone では **ホーム画面に追加して使う** のがおすすめです（Safari で開くだけだと、長期間使わないとデータが消えることがあります）
- 機種変更のときは ⚙️ →「バックアップ」の「コピー」で文字列を保存し、新しい端末で「読みこむ」

## カスタマイズ

アイテムやマシンは `js/data.js` の `MACHINES` を編集するだけで追加・変更できます。

```js
{ id: 'mymachine', name: 'マシン名', icon: '🎀', price: 300, color: '#ff8fb8', unlock: 1,
  items: [ ['key', 'アイテム名', '🎀', 'N', 'ひとこと'], /* ... */ ] }
```

レア度は `N` / `R` / `SR` / `SE`（シークレット）。6つ目の要素に `'gold'` か `'rainbow'` を入れると特殊エフェクトがつきます。
内容を更新したら、`sw.js` の `CACHE` の名前（`pocket-gacha-v1` → `v2`）も変えると確実に反映されます。

## ファイル構成

```
index.html             画面の骨組み
css/style.css          デザイン
js/data.js             マシン・アイテム・ミッション・実績の定義
js/app.js              ゲーム本体
sw.js                  オフライン対応（Service Worker）
manifest.webmanifest   ホーム画面追加用の設定
icons/                 アプリアイコン
.github/workflows/     GitHub Pages への自動デプロイ
```
