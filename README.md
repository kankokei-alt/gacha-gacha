# 🎰 ガチャモン

本物のガチャガチャを **がまんすると回せる**、**リアルのご褒美が当たる** おうちガチャアプリです。
ホーム画面に追加すればアプリのように使え、オフラインでも遊べます。

## しくみ

```
本物のガチャをがまん →「がまん」タブから申請 → LINEで管理者（だんなさん）へ
                                                  │ 管理ページで認定
ガチャ券がもらえる（1回につき3枚） ←─ LINEで認定リンクが返ってくる
        │
        ▼
アプリのガチャを回す ─┬─ 当たり：🍮デザート / 🍝カフェ・ランチ / 🍣お寿司 チケット →「ごほうび」タブで使う
                      └─ はずれ：ガチャモン・家族のキャラが出て「ずかん」に登録
```

| 要素 | 内容 |
| --- | --- |
| 🎫 ガチャ券 | 唯一の通貨。1枚で1回。毎日6時・14時・22時に1枚（3枚までたまる）、毎日ログインで1枚（7日目は3枚）、がまん認定、実績、レベルアップでもらえる |
| 💪 がまん | 「がまんした！」を押して申請 → 管理者が認定すると 🎫3枚（管理者が増減できる） |
| 🎁 ごほうび | 当たったリアルチケットの一覧。「使う」を押すと使用済になり、管理者にLINEで知らせられる |
| 📖 ずかん | はずれの時に出るキャラ。ガチャモン40種＋家族20人（すべてオリジナルの手描きSVG）。レベル・実績もここ |
| 🔑 管理ページ | `admin.html`。申請の認定／見送り、ガチャ券のプレゼント、今月のまとめ |

### 当たりの確率と予算

| 当たり | 金額 | 確率 |
| --- | --- | --- |
| 🍮 デザートチケット（コンビニで1人200円くらいのスイーツかおやつ） | 200円 | 2% |
| 🍝 カフェ・ランチチケット（休日のお昼ごはん） | 4,000円 | 0.2% |
| 🍣 お寿司チケット（回転寿司） | 5,000円 | 0.1% |
| 🍷 豪華ディナーチケット（ふたりで1万円） | 10,000円 | ガチャモン全40種コンプで1回 |

1回あたりの平均は約17円。1日約4.7回（月143回）まわすと平均 約2,400円 です（ガチャモンのコンプでもらえるディナー1万円は別）。
上限はなく、確率で平均がこのくらいになるように調整しています。
がまん1回 → 🎫3枚 → ご褒美の平均 約50円。本物のガチャ（300〜500円）より安く済みます。
これらの数字は `js/data.js` の先頭で変えられます。

### 認定のしくみ（サーバーなし）

管理ページで作った「カギ」（電子署名）で認定リンクに印をつけ、アプリ側で確かめます。
カギは管理者のスマホの中だけにあるので、認定リンクは管理者にしか作れません。同じリンクは1回しか使えません。

- 管理ページは iPhone なら **Safari で開いて** 使ってください（ホーム画面に追加するとカギが見つからなくなります）
- アプリをホーム画面に追加している場合、LINEのリンクは Safari で開くため、アプリには届きません。
  そのときはリンクをコピーして、アプリの「コードを貼りつける」から読みこみます

## 公開方法（GitHub Pages）

ビルド不要の静的サイトなので、GitHub Pages でそのまま公開できます。

1. このブランチを `main` にマージする
2. GitHub のリポジトリで **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. `main` に push すると `.github/workflows/pages.yml` が自動で公開する（Actions タブから手動実行も可能）
4. `https://<ユーザー名>.github.io/gacha-gacha/` をスマホで開く
5. iPhone: Safari の共有ボタン →「ホーム画面に追加」／ Android: Chrome のメニュー →「ホーム画面に追加」

> 無料プランの GitHub Pages は **公開リポジトリ** が必要です。リポジトリを非公開のままにしたい場合は、
> [Netlify Drop](https://app.netlify.com/drop) や Cloudflare Pages にフォルダごとアップロードしても動きます。

### ローカルで動かす

```bash
npx serve .        # または python3 -m http.server
```

## データについて

- データはその端末のブラウザ（localStorage）にだけ保存され、外部には送信されません（LINEで送るリンクの中身を除く）
- iPhone では **ホーム画面に追加して使う** のがおすすめです（Safari で開くだけだと、長期間使わないとデータが消えることがあります）
- 機種変更のときは ⚙️ →「バックアップ」の「コピー」で文字列を保存し、新しい端末で「読みこむ」

## カスタマイズ

当たりの種類・確率は `js/data.js` の `PRIZES`、がまん1回のガチャ券は `GAMAN_TICKETS` で変えられます。
キャラの名前・レア度・説明は `js/data.js` の `MACHINES`、イラストは `js/art.js` にあります。

```js
// js/data.js（1行が1キャラ）  [ID, 名前, レア度, 説明, タイプ]
['moririn', 'モリリン', 'N', 'あたまの芽は…', ['くさ']],
```

レア度は `N` / `R` / `SR` / `SE`（伝説）。キャラを足すときは、`js/art.js` に同じIDのイラストも追加します。
内容を更新したら、`sw.js` の `CACHE` の名前（`pocket-gacha-v14` → `v15`）も変えると確実に反映されます。

## ファイル構成

```
index.html             画面の骨組み
css/style.css          デザイン
js/data.js             当たり・確率・キャラの名前と説明・実績の定義
js/art.js              キャラのイラスト（手描きSVG）
js/app.js              ゲーム本体
js/link.js             LINEで送るリンクと電子署名
admin.html, js/admin.js 管理ページ（だんなさん用）
sw.js                  オフライン対応（Service Worker）
manifest.webmanifest   ホーム画面追加用の設定
icons/                 アプリアイコン
.github/workflows/     GitHub Pages への自動デプロイ
```
